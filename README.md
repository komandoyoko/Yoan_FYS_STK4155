# Machine Learning Projects

This repository contains three group projects from **FYS-STK4155 – Applied Data Analysis and Machine Learning** at the University of Oslo.

The projects were completed as part of my master's studies in microelectronics and sensor technology. The focus is on implementing machine learning methods, testing them on numerical datasets, and understanding how model choices affect performance.

## Projects

### Project 1 – Regression methods and resampling

This project investigates regression methods on the Runge function.

Main topics:

- Ordinary Least Squares (OLS)
- Ridge regression
- LASSO regression
- Polynomial regression
- Closed-form solutions and gradient descent
- Stochastic gradient descent
- Momentum, AdaGrad, RMSProp and Adam
- Bootstrap resampling
- Cross-validation
- Bias–variance trade-off

The goal was to compare how different regression and regularization methods behave as model complexity increases.

### Project 2 – Feedforward neural networks

This project focuses on implementing feedforward neural networks from scratch.

The implementation was tested on:

- Runge function regression
- MNIST handwritten digit classification

Main topics:

- Neural network architecture
- Forward propagation
- Backpropagation
- Activation functions: sigmoid, ReLU and Leaky ReLU
- Cost functions for regression and classification
- Optimizers: gradient descent, RMSprop and Adam
- Hyperparameter tuning
- Batch size and learning rate experiments
- Model validation against established ML libraries

The goal was to understand how network depth, activation functions and optimization methods affect learning and generalization.

### Project 3 – Machine learning project

The third project is included as a notebook. It continues the course work in applied machine learning and documents additional experiments, methods and analysis.
